# Thomas Dreibholz's Homebrew Tap

This repository provides up-to-date packages for:

* [BibTeXConv](https://www.nntb.no/~dreibh/bibtexconv/) – BibTeX File Converter
* [DynMHS](https://www.nntb.no/~dreibh/dynmhs/) – Dynamic Setup of Multi-Homing IP Routing Rules
* [FractGen](https://www.nntb.no/~dreibh/fractalgenerator/) – Extensible Fractal Generator Software
* [HiPerConTracer](https://www.nntb.no/~dreibh/hipercontracer/) – High-Performance Connectivity Tracer
* [NetPerfMeter](https://www.nntb.no/~dreibh/netperfmeter/) – TCP/MPTCP/UDP/SCTP/DCCP/QUIC Network Performance Meter Tool
* [SubNetCalc](https://www.nntb.no/~dreibh/subnetcalc/) – IPv4/IPv6 Subnet Calculator
* [System-Tools](https://www.nntb.no/~dreibh/system-tools/) – Tools for Basic System Management
* [TSCTP](https://www.nntb.no/~dreibh/tsctp/) – SCTP Test Tool

## How do I install these formulae?

Use:

```bash
brew install dreibh/tap/<formula>
```

Or:

```bash
brew tap dreibh/tap
brew install <formula>
```

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dreibh/tap"
brew "<formula>"
```
